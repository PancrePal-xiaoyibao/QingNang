# 演示数据目录（synthetic）

> **仓库内禁止出现任何真实患者数据。**

本目录存放**合成的**演示数据 —— 由脚本生成，结构完整但内容全部虚构。

## 用途

- 测试知识卡与话术在真实数据结构下的表现
- 演示隐私隔离流程（解析 → 写入 `private/` → 不外泄）
- 给贡献者一个「可以随便改、随便提交」的沙盒

## 规则

| ✅ | ❌ |
|---|---|
| 用造数脚本生成 | 手写一段看起来像真病历的文本 |
| 全虚构内容 | 任何来自真实患者的信息 |
| 提交到仓库 | 把 `~/.qingnang/private/` 的东西复制过来 |

## 造数脚本

```bash
# 生成一套合成演示数据（报告单文本、指标序列、就诊记录骨架）
python3 data/synthetic/gen_demo_data.py --out data/synthetic/demo/
```

> 脚本**待 M3 实现**。在此之前请勿手工创建演示数据 —— 手工造的容易无意带上真实信息。

## 与 `private/` 的区别

| | `data/synthetic/`（本目录） | `~/.qingnang/private/` |
|---|---|---|
| 内容 | 全虚构 | 真实患者数据 |
| 位置 | 仓库内，**会提交** | 本机 HOME，**永不提交** |
| 用途 | 测试与演示 | 用户实际使用 |
| 可删 | 可 | **绝不可**（那是运行数据） |
