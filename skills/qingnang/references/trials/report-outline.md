> **来源**：改进后并入自社区 skill `opencare-skillhub/clinicaltrials-query-analysis`（Apache-2.0）。
> **改动**：抽取其「标准化报告提纲」作为本包的报告骨架；补充青囊的医学红线约束；移除了与本包无关的公众号排版细节。
> **许可**：Apache-2.0（保留原许可，见 `references/SOURCES.md`）

---

## 什么时候用

用户要**成体系的试验调研**（不是单条查询）时用本提纲。例如：
- 「帮我整理一下胰腺癌 KRAS 靶点的临床试验现状」
- 「CLDN18.2 现在有哪些在招的试验，中国有哪些中心」

**与 `SEARCH_RUNTIME.md` 通道 4 的分工**：本文件是**报告的骨架**；实际检索调 `qingnang_trial`（通道 4）。

---

## 标准化流水线（四步）

```
① 检索   → 调 qingnang_trial，多关键词覆盖（靶点别名 + 适应症 + 药物名）
② 富化   → 抓详情：PI、联络方式、中国中心医院
③ 组稿   → 按下方固定提纲生成中英对照报告
④ 标注   → 每条带登记号（NCT / ChiCTR）；标注采集时间
```

**四步都要做**。只做 ① 就出结论 = 不合格（缺入组标准与中心信息，患者无法行动）。

---

## 固定报告提纲（七章，每章必含字段）

| 章节 | 内容 | 必含字段 |
|---|---|---|
| **1. 检索结果概览** | 总试验数、招募状态分布、阶段分布、治疗类型分布、申办方 Top10、地理分布 | 中英对照统计表格 |
| **2. 靶点介绍与治疗原理** | 靶点基本信息、生物学功能、表达谱、治疗原理（ADC / CAR-T / PROTAC 等机制） | 中英对照 + 机制说明 |
| **3. 临床试验清单** | 按治疗类型分组的完整试验表格 | **NCT 编号**、药物、靶点、适应症、阶段、状态、**中国 flag** |
| **4. 🇨🇳 中国中心专题** | 每项中国试验的 PI 姓名、各中心医院、联系人 | **PI 必含**、医院详情 |
| **5. 📊 可及性分析** | 中国患者可及性评分、费用医保评估、城市中心分布 | 分维评分 + 地理分布 |
| **6. 🔭 前景展望** | 时间线、企业进展、关键技术挑战 | 里程碑 |
| **7. 📋 患者建议** | 当前可及选项、下一步行动 | 行动项 + 可及性导航 |

## ⚠️ 青囊附加约束（**本包强制，原上游没有**）

上游 skill 面向运营场景，本包面向**病友**，因此加四条硬约束：

| # | 约束 | 说明 |
|---|---|---|
| **C1** | **第 7 章「患者建议」不得给治疗建议** | 只能给「可以去问医生什么」的清单，不能给「你应该参加哪个试验」。触发红线 **M1**。 |
| **C2** | **第 5 章「可及性分析」不得承诺医保结论** | 只能说「据 XX 来源，该药截至 YYYY-MM 未纳入 / 已纳入国家医保目录」，并给官方查询链接。 |
| **C3** | **所有招募状态必须带采集时间** | 试验状态变化快，「正在招募」这个结论只在采集时刻有效。格式：`截至 2026-10-14`。 |
| **C4** | **中国中心联系人只提供公开渠道** | 不做私人联系方式传播；电话/邮箱若来自注册平台公开页，需注明来源 URL。 |

## 输出的最小合格标准

一份合格的试验专题报告**至少**满足：

- [ ] 每条试验有 **登记号**（NCT / ChiCTR / 中国登记平台号）
- [ ] 每条试验有 **采集时间**
- [ ] 中国试验标注了**中心医院**与 **PI**（若注册信息中有）
- [ ] 招募状态明确区分「招募中 / 已完成 / 未开始 / 已终止」
- [ ] 第 7 章是**问题清单**，不是治疗建议
- [ ] 末尾附免责声明

**缺任一项 → 报告不合格，需补全再交付。**

## 靶点关键词速查

检索时**靶点别名要覆盖全**，否则会漏试验：

| 靶点 | 常用别名 / 写法 |
|---|---|
| CLDN18.2 | Claudin 18.2, CLDN18.2, Zolbetuximab 相关 |
| KRAS | KRAS G12C, G12D, G12V, pan-KRAS, RAS(ON) |
| B7-H3 | CD276, B7H3 |
| HER2 | ERBB2, HER-2 |
| MSI-H / dMMR | microsatellite instability, mismatch repair |
| NTRK | NTRK1/2/3, TRK fusion |
| BRCA | BRCA1, BRCA2, HRD |

**用法**：检索时把别名一起发出去（并行多关键词），不要只发一个。
