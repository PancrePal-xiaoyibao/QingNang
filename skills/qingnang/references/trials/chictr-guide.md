## ChiCTR 是什么

中国临床试验注册中心。**国内试验的权威登记源之一。**

**与通道 4 的关系**：`unified-trial-mcp`（通道 4）**已覆盖 ChiCTR**。本文件是**检索参数的说明**——当你需要精确控制 ChiCTR 检索时看这里。

> ⚠️ **不要**为了查 ChiCTR 而再装一个单通道 MCP。通道 4 够了。

## 检索参数

| 参数 | 约束 | 说明 |
|---|---|---|
| 关键词 | **最长 200 字符** | 注册题目关键词 |
| 注册号 | `ChiCTR` + **至少 8 位数字** | 精确检索或详情查询 |
| 年份 | 2000 至当前年份 + 1 | 注册年份 |
| 结果上限 | **1–100** | 有分页保护上限 |

**优先用注册号精确查**，少用宽泛关键词高频扫描。

---

## 结果解读的边界（**重要**）

| 事实 | 含义 |
|---|---|
| 列表页与详情页是**网页抓取结果** | **不是**规范化临床数据源 |
| `project_id` 是详情页内部标识 | **不能替代** `registration_number` |
| 页面字段可能缺失 / 网站可能改版 | 空字段或失败属正常现象 |
| 可能遇到验证码 / 访问冷却 | **不绕过**；记录失败原因 |

### 采集/检索的四条纪律

1. **记录上下文**：查询条件、时间、来源 URL 一起记录，否则结论不可复现。
2. **空结果的含义**：「没查到」**不等于**「没有这项研究」——可能是关键词不匹配、网站改版或限制。
3. **保留原始标识**：输出时必须带 `registration_number` + `source_url`。
4. **联系人最小必要**：结果可能含联系人信息。**不传播**非必要的电话与邮箱。

## 给 Agent 的硬约束

| ❌ 不做 | ✅ 应该做 |
|---|---|
| 绕过验证码 / 反爬 | 遇到就停，如实告知用户 |
| 把空结果解释成「没有任何研究」 | 说「本次未检索到，可能是关键词或平台限制」 |
| 把网页字段当临床事实 | 说「据 ChiCTR 注册信息显示」，并给原始链接 |
| 高频扫描 | 优先精确注册号；批量时限制结果数 |
| 传播联系人电话 | 只给公开的注册页链接 |
